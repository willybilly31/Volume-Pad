# Voluma

Xiao RP2040 based volume/macropad made to make my desk setup easier to use. I was going to make a regular old macropad with just buttons, but i realized that sometimes i would want to change the volume of individual apps on my pc but that can be annoying to do.

## Hardware
- Xiao RP2040
- Addressable RGB LED
- 3 Cherry MX switches
- 3 PTA4543-2015CPB503 slide potentiometers

## Features
- Slide potentiometers for volume controls
- Keyboard Switches for Macros/Shortcuts
- RGB LED
